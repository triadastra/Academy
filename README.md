# Synonance

The default Syno application: a high-fidelity interactive prototype for
course-grounded tutoring, mastery tracking, teacher insights, assessment
building, content management, and institutional administration.

## Run locally

```sh
npm install
npm run dev
```

The app opens at `/login`. Use the floating role control to jump between the
student, teacher, and admin demo areas.

## Checks

```sh
npm run build
npm run lint
```

The application uses simulated data and interactions. No backend or live AI
service is connected in this version.
