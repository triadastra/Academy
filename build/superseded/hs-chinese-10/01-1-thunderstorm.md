# 1.1 《雷雨》曹禺

## 基本信息

| 项目 | 内容 |
|---|---|
| **作者** | 曹禺（本名万家宝） |
| **创作年份** | 1934 年 |
| **体裁** | 话剧，悲剧 |
| **背景地点** | 天津 |
| **两个家庭** | 周家、鲁家 |
| **时间跨度** | 三十年 |

## 人物关系

| 人物 | 身份与关系 |
|---|---|
| **周朴园** | 周家家长，资本家 |
| **鲁侍萍** | 三十年前被周朴园抛弃的女子 |
| **繁漪** | 周朴园之妻，**周萍的继母**，与周萍有不伦之恋 |
| **周萍** | 周朴园与侍萍之子 |
| **四凤** | 鲁侍萍与鲁贵之女，与周朴园**无血缘关系** |
| **鲁大海** | **工人代表**，参与罢工斗争 |
| **周冲** | 周朴园与繁漪之子 |
| **鲁贵** | 周家仆人，四凤之父 |

理清人物关系是理解全剧的关键。**四凤与周朴园无血缘关系**——她是侍萍与鲁贵所生——这一点常被误解，而剧本正是利用这种血缘与身份的错综来制造悲剧。

## 重要情节与理解要点

**周朴园保留侍萍旧家具、熟记其生日**

表面看似"真心怀念旧情"，**本质是虚伪作态，维护自身形象**。他怀念的是一个已经死去、不会回来打扰他的侍萍；当真人出现时，他的反应立刻暴露了这种怀念的性质。这是全剧最重要的人物讽刺。

**繁漪与周萍**

繁漪是周萍的**继母**，二人有不伦之恋。繁漪是全剧最具反抗性的人物——她的"雷雨"性格既是被压抑的结果，也是推动情节爆发的力量。

**鲁大海**

**工人代表**，参与罢工斗争。他的存在把家庭悲剧与阶级冲突联系起来：周朴园既是他的雇主，也是他的生父。

**结局**

**四凤、周冲在雷雨中触电身亡**。侍萍三十年前**除夕跳河**未死，正是这一"未死"使三十年后的重逢与悲剧成为可能。

## 主题

- **封建家庭的压抑与崩溃**——旧秩序表面完整，内部早已腐坏
- **命运与巧合**——三十年前的因，三十年后的果
- **阶级冲突**——资本家与工人的对立贯穿家庭内部
- **虚伪与真实**——周朴园的"深情"是全剧对虚伪最集中的刻画

"雷雨"既是剧中的天气，也是全剧的结构隐喻：闷热积压之后，一场雷雨在一日之内把三十年的隐秘全部揭开、并将其摧毁。
